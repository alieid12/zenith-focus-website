## Short description
Zenith is a free iPhone focus timer that turns completed focus sessions into a growing virtual garden. Use Strict Mode to help reduce distractions and ambient sounds to create a calmer focus environment.

## Longer description
Build a more consistent focus routine, one session at a time. Zenith pairs a simple focus timer with a virtual garden that grows as you complete sessions, giving your effort a visual reward. Strict Mode is designed to help reduce distractions, while ambient focus sounds help you shape a calmer work environment.

Zenith is made for iPhone and is free to download.
