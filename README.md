# Zenith landing page

This is a static, mobile-first landing page for Zenith: Focus Timer & Plant.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `zenith-landing`.
2. Upload `index.html` and `robots.txt` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published URL when deployment finishes.

## Before sharing
- Open the published page on iPhone and desktop.
- Tap every App Store CTA and confirm it opens the official listing.
- If you later use a custom domain, update the canonical/social URL and add a sitemap with that domain.
- This project contains no analytics trackers, cookies, fabricated reviews, or paid integrations.
