# Zenith SEO + organic growth pack

Prepared 2026-10-24.

This is a ready-to-apply package, not a live deployment. The connected GitHub integration previously returned HTTP 403 for writes, so no production website files were changed.

## Contents
- `robots.txt` — allows crawling and points crawlers to the sitemap.
- `sitemap.xml` — lists the English landing page and proposed Arabic landing page.
- `english-head-snippet.html` — alternate-language metadata to merge into the existing English page head.
- `ar/index.html` — proposed Arabic landing page, using the existing GitHub Pages base path.
- `directory-listing-copy.md` — ready-to-paste directory listing content and submission checklist.
- `social-posts.md` — three organic short-video concepts and captions.

## Apply safely
1. Review `ar/index.html` and confirm the Arabic wording and app features.
2. Merge the `english-head-snippet.html` alternate-language links into the existing `index.html`; avoid duplicate canonical tags.
3. Upload `robots.txt`, `sitemap.xml`, and the `ar/` folder to the root of the existing GitHub Pages repository.
4. Check that the pages load and both language versions link to each other.
5. Submit the App Store URL to free directories manually where no authorized form-submission tool is available.
6. Record each submission only after confirmation and save the live listing URL.
