## Growth strategy
1. Improve conversion and trust: accurate store listing, clear value proposition, resolved bugs, review response, clear iOS availability.
2. Acquire qualified attention: useful study/focus content, short-form video tests, Arabic + English, search-led guides and ethical community participation.
3. Improve activation/retention: first-session clarity, session reliability, habit formation, review monitoring.
4. Measure installs, product-page conversion, retention and source attribution—not views alone.
5. Iterate based on actual post-level and App Store data.

## Current experiment rules
- Test hooks and creative formats, not just captions.
- Prefer video demonstrations and authentic use cases over repeated static feature lists when video assets are available.
- Track views, likes, comments, shares, average watch time, completion rate, profile visits, link taps and attributed installs where available.
- Treat social views as reach signals, not install attribution.
